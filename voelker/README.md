# Herkunftsbilder

Sieben neue illustrative Beispielporträts, keine Ersatzporträts für konkrete Spieleridentitäten. Built-in ImageGen, Neugenerierung ohne Referenzbilder. Alle Originale bleiben im generated_images-Ordner erhalten. Dateien visuell geprüft; Auslieferung als PNG.

Der Imagegen-Skill beeinflusste Motivstruktur und Qualitätsprüfung: mittelalterliche Schenke, warme Kerzen, ruhige reisende Figuren, kein Bildtext.
